# 🎤 FRIDAY NIGHT FUNKIN' — BROWSER EDITION

**A browser-based rhythm game inspired by Friday Night Funkin'.**

A custom-built rhythm game featuring music synchronization, arrow-based gameplay, character animations, song selection, scoring, and a fully interactive interface.

---

## 🎮 About the Game

This project is a JavaScript-powered rhythm game inspired by Friday Night Funkin' (FNF).

The objective is simple: hit the notes in time with the music, maintain your combo, and achieve the highest possible score.

The game is designed to bring the FNF experience into the browser without requiring a traditional game installation.

## ✨ Features

- **Freeplay Mode** — Browse and select individual songs.
- **Rhythm Gameplay** — Four-lane arrow-based note system.
- **Music Synchronization** — Notes synchronize with song timing.
- **Difficulty Settings** — Adjustable gameplay difficulty.
- **Scoring System** — Earn points for accurate hits.
- **Combo System** — Build combos by hitting consecutive notes.
- **Accuracy Tracking** — Monitor your performance.
- **Miss Detection** — Track missed notes.
- **Character Sprites** — Support for custom character sprite sheets.
- **Song Sorting** — Organize tracks alphabetically.
- **Shuffle Mode** — Randomize song selection.
- **Custom HUD** — Score, combo, misses, and accuracy display.
- **Settings** — Customize gameplay preferences.

## 🚀 Installation

1. Open your browser.
2. Open your JavaScript testing environment.
3. Paste the complete game code.
4. Run the code.
5. Wait for the game interface to initialize.
6. Select a song and start playing!

No separate game engine is required.

## 🛠️ Technology

- JavaScript
- HTML5 Canvas
- CSS
- Web Audio / YouTube integration

## 💾 Save Data

The game uses browser LocalStorage to preserve supported information, including:

- Player preferences.
- Selected difficulty.
- Note speed.
- Best scores.
- Song-related settings.

Clearing browser storage may reset saved progress.
